# 001 — Bmp3xx sample on real hardware (plan Step 13, first pass; pasted by Timothy, recorded by desktop Claude)
Date: 2026-10-11
Pi: Raspberry Pi 4 Model B Rev 1.2, Raspberry Pi OS 32-bit userland (getconf LONG_BIT = 32, dpkg arch = armhf)
    on a 64-bit kernel (6.1.21-v8+, uname -m = aarch64)
Board: Adafruit BMP390 (product 4816) at 0x77, STEMMA QT cable, I2C bus 1
Binding: fork branch feature/bmp3xx-binding @ 8d23d3d4
Build (Mac): dotnet publish iot/src/devices/Bmp3xx/samples/ -c Release -r linux-arm --self-contained -o scratch/new-device-binding/publish/sample-arm32
Note: the first publish used -r linux-arm64 -> "./Bmp3xx.Samples: No such file or directory" (64-bit loader missing
      on a 32-bit userland). uname -m reports the kernel, not the userland; use dpkg --print-architecture.
Command (Pi): ./Bmp3xx.Samples | tee sample-run-$(date +%F).txt   (run twice; the second run overwrote the file on the Pi)
Sample settings: pressure x8, temperature x1, IIR coefficient 3; then normal mode, ODR 40 ms (25 Hz)
