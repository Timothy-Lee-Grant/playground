## 4. Discoveries
- **verified** (`003`): `HttpSysDelegator` is `internal sealed`, and AutoMock built a **real** one rather than a mock. The rewrite builds it explicitly with `new HttpSysDelegator(server.Object, NullLogger…)`, so the middleware tests still exercise the same real code.
- **verified** (`003`): AutoMock's loose defaults are exactly `new Mock<T>()`'s, so the "loose-default trap" is met by Moq's own defaults.
- **verified** (`003`): no test in the 7 files looks at a logger, so `NullLogger<T>.Instance` is safe everywhere.
- **verified** (`003`): `ForwarderMiddlewareTests.NoDestinations_503` calls `.Verify()` with nothing marked `.Verifiable()`, so that line checks nothing. I left it unchanged because it's out of scope. It's a possible follow-up for the PR description; that's Timothy's call (lecture 001 §8).
- **verified** (`004`): O2 needs `--no-incremental`. One break stayed green because of a stale incremental build. I re-ran every break with a forced rebuild.
- **verified** (`011`): Kubernetes.Tests and FunctionalTests skips equal `main`'s. This closes Step 7's open item.
- **verified** (`011`): `./build.sh` passes `/warnaserror`, but plain `dotnet build` doesn't.
- **verified** (`011`): `./test.sh` only runs tests; without a build it "fails" in about 1 s.
- **verified** (`002`): `--filter-method` with a short name silently matches 0 tests.
- **verified** (`002`): the documented `dotnet test test/ReverseProxy.Tests/` fails with a doubled path, but an absolute `--project` path works. **Cause unverified.**
